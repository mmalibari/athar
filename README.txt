أثر · خطوات التشغيل

1) Supabase (مرة واحدة)
- افتح مشروعك > SQL Editor > New query
- الصق محتوى setup.sql واضغط Run

2) الرفع
- ارفع محتويات هذا المجلد إلى الريبو mmalibari/athar
- اربطه بـ Netlify أو Cloudflare Pages (أو GitHub Pages)

3) الروابط
- /present  شاشة العرض
- /control  التحكم
- /join     الطلاب (رمز QR يظهر على شاشة الدخول)

قبل كل جلسة: من /control اضغط «مسح بيانات الجلسة»
